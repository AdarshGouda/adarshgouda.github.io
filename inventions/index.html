Inventive practice

Define the contradiction before proposing the mechanism.

I tend to start by identifying the physical or system contradiction: a measurement that is difficult to obtain, an operating mode that creates a new failure path, an architecture constrained by power or telemetry, or an interface that forces an unnecessary compromise.

From there, I separate the inventive principle from one implementation, check prior art, model the governing behavior where useful, and test whether the concept retains value when specific hardware details change.
