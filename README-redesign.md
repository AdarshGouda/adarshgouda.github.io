# Portfolio redesign 2026

This branch contains a new technical-editorial portfolio for Adarsh Gouda.

## Structure

- `index.html` — curated homepage
- `assets/site.css` — design tokens, layout, components and responsive rules
- `assets/site.js` — mobile navigation, scroll progress and restrained reveal motion
- `work/` — selected work and case studies
- `ideas/`, `about/`, `experience/`, `inventions/`, `resume/` — core portfolio sections

The redesign reuses public project imagery and notebooks already present in the repository. It intentionally omits unpublished program details, internal invention disclosures and confidential company information.

The original site is preserved on `main` and at `archive/current-site-2026-09-06`.
